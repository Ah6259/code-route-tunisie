Je prends mon Pass

Prix en dinars tunisiens. Voir les conditions du Pass Examen.

Comment ça marche ?

  1. Remplissez le formulaire (nom, téléphone WhatsApp et e-mail) : il vous donne tout de suite votre numéro de commande.
  2. Payez par D17 ou IZI avec ce numéro comme motif du paiement, puis envoyez la preuve par WhatsApp (le message contient déjà votre numéro).
  3. Dès que le paiement est vérifié (en général sous 24 heures), ce même numéro devient votre code d'accès : sur ce téléphone, la page l'essaie toute seule ; ailleurs, tapez-le une fois dans « J'ai un code ».
